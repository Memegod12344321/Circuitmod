# Minecraft Java 1.21.11 — Background Optimizer

## Custom title-screen background

Replace the six panorama images in:

assets/minecraft/textures/gui/title/background/

with your own images:

- panorama_0.png
- panorama_1.png
- panorama_2.png
- panorama_3.png
- panorama_4.png
- panorama_5.png

The six images form Minecraft's rotating 360° title-screen panorama.

For a normal flat picture, the image needs to be converted/cropped into six panorama faces. Simply putting one normal 1920x1080 image into this folder will NOT automatically make Java use it as a full-screen background.

## Version

Minecraft Java Edition 1.21.11.
