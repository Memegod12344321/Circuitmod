# Llama KDP Notebook Generator

A mobile-first notebook generator for Amazon KDP interiors and covers.

## Features
- Llama-compatible OpenAI-style API endpoint/model/key settings
- AI-assisted title, subtitle, description, keywords, themes and page prompts
- Lined, wide-ruled, college-ruled, graph, dot-grid, blank, checklist, planner and journal interiors
- Custom trim sizes, page count, margins, bleed and line spacing
- Live page preview
- Cover planner with spine-width estimate
- Print-ready PDF export using the browser
- Overpowered mode with advanced controls
- Local project save/load and JSON export/import
- No API key is hard-coded into the repository

Open `index.html` directly for the web app. For production hosting, GitHub Pages can serve the static files.

## Llama setup
Enter your compatible API endpoint, model and key in Settings. The app sends requests only when you press an AI generation button.

## KDP note
Always verify the generated PDF dimensions, margins, bleed, page count and current KDP specifications before publishing.
