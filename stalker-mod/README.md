# The Stalker — Forge 1.20.1

A tall hostile horror mob for Minecraft Forge 1.20.1 (Java 17).

## Current features
- Tall entity hitbox and enlarged renderer.
- 60 health, fast movement, heavy melee attacks, and knockback resistance.
- Searches for and chases nearby players within its follow range.
- Spawn egg named The Stalker Spawn Egg.
- Uses the vanilla zombie texture as a placeholder; a custom model/texture can be added later.

## Build
GitHub Actions downloads the Forge 1.20.1 MDK, injects this source project, runs Gradle build, and uploads the compiled JAR as an Actions artifact.

## Spawn
After installing the compiled JAR, use the spawn egg or run: /summon thestalker:stalker
