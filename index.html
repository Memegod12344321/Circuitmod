Important: A static webpage cannot upload files into your GitHub repository without GitHub authorization. After choosing your ZIP, upload it to the repository's uploads/ folder using the GitHub link above. That upload starts the build. The current automated workflow is set up for Gradle source projects; Forge, Fabric, and NeoForge projects need their own compatible build files. A compiled JAR or a decompiled folder alone is not a source project.
