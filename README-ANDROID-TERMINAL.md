# Circuit Terminal

Android companion app for CircuitMod.

## Prototype
- Termux-like terminal UI.
- Runs shell commands through Android's shell.
- Optional localhost API on 127.0.0.1:8765.
- API is disabled until the user enables it.
- Intended future path: authenticated ChatGPT/AI control through an explicit tunnel.

## Security
Keep the API local-only. Before any public/tunneled release, add authentication, command approval, and an allowlist.
